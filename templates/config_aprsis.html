Server APRS-IS -g
ⓘ
udpgate4 può utilizzare più server APRS-IS. I server vengono provati in ordine di priorità: il primo server attivo è il preferito.
Se il collegamento passa a un server successivo, udpgate4 continua a controllare quelli con priorità maggiore e torna automaticamente al preferito quando disponibile.

Filtro backstream globale -f

Attesa prima della riconnessione -e
Secondi prima del collegamento o della riconnessione al prossimo gateway. Default: 30.
Connessione su richiesta -k
0 = sempre connesso. Un valore maggiore mantiene il collegamento per quel numero di secondi dopo l'ultimo traffico valido.
Timeout coda TCP -T
Chiude il link se i byte TCP non confermati rimangono troppo a lungo in coda. 0 = disabilitato, massimo 60 s, default 15.
